# Java Jungle

Java Jungle is a Java desktop game with a jungle theme. Players can create a profile or choose a saved player, select a game mode, and work through interactive Story Mode cases using the code editor.

## Features

- Illustrated jungle welcome screen
- New-player setup with a name and avatar selection
- Saved-player profiles and returning-player flow
- Multiple game modes
- Story Mode cases with descriptions and diagnostic feedback
- Scrollable case text, feedback, and code editor

## Built with

- Java
- JavaFX and FXML

## Getting started

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure the project is configured with the required JDK and JavaFX dependencies.
4. Run the application's main class from IntelliJ IDEA.

> The exact JDK version and run command depend on the project configuration. Check the build files or IntelliJ run configuration for the required setup.

## How to play

1. Start the game from the welcome screen.
2. Create a new player or select a saved profile.
3. Choose a game mode.
4. In Story Mode, read the case, work in the code editor, and review the feedback.

## Project structure

Java Jungle uses Java source files and FXML resources for its screens. The user interface resources are under `src/main/resources/org/javajungle/`.
